# MV Easy

音楽と歌詞からMVを自動生成し、必要に応じてタイムラインで編集できる日本語のアプリです。

## 起動

Node.js 22.18 以降で実行してください。

```sh
npm ci
npm run dev
```

Vite が表示するローカル URL をブラウザーで開きます。

## MVを自動生成

1. 音楽を読み込み、歌詞を改行ごとに貼り付けます。空行は飛ばします。
2. 再生して、各行の歌い出しでスペースキーを押します。記録は「1つ戻る」で取り消せます。「記録時刻を修正」を開くと開始秒と最後の歌詞の終了秒を調整できます。
3. 「MVを自動生成」でプレビューを作成します。「もう一度生成」で演出を変え、「生成履歴」で以前の結果に切り替えられます。
4. 「動画を保存」でMP4を書き出せます。「詳細編集」では生成した歌詞・背景・アニメーションを編集できます。

「プロジェクトを保存」で音楽と同期時刻、生成履歴を含む `.mveasy` ファイルを保存できます。同じブラウザー・同じURLでは、編集中のプロジェクトが自動復元されます。

## 詳細編集

- 「＋追加」からテキスト・四角形・円を追加し、右のプロパティで位置、サイズ、回転、色を調整します。
- レイヤーを選んで左のテンプレートを押すと、再生位置付近にアニメーションが追加されます。同じレイヤーに複数追加できます。
- レイヤー名の左にある矢印でアニメーションを展開します。バーの中央をドラッグすると移動し、左右の端をドラッグすると長さを変えられます。
- レイヤー名をクリックすると展開・折りたたみできます。レイヤー名を上下にドラッグするとオブジェクトの重なり順を、アニメーション名を上下にドラッグすると同じレイヤー内の合成順を変更できます。
- Alt＋←／→で再生ヘッドを前後の端点へ移動します。バーの開始端または終了端にフォーカスして Shift＋Alt＋←／→を押すと、その端点を 0.1 秒ずつ動かせます。
- スペースキーで再生・一時停止します。編集中のテキスト欄では通常どおりスペースを入力できます。
- タイムラインの上端を上下にドラッグして高さを変更できます。高さはブラウザーに保存されます。
- プレビューでオブジェクトをドラッグして移動し、選択枠の四隅でサイズを変更できます。Ctrl＋Z でプレビュー上の移動・サイズ変更を1操作ずつ取り消せます。
- 時間目盛りやトラックの空いているところをクリックすると、その位置から確認できます。

- 「＋追加」→「音楽を読み込む」で音楽トラックに1曲を配置します。MP3・WAVに対応し、M4Aはブラウザーが対応するコーデックで読み込めます。
- 音楽バーをドラッグして配置し、左右の端をドラッグしてトリミングします。音量・ミュート・削除・再リンクは音楽クリップを選ぶと操作できます。
- タイムラインのズームで波形を拡大できます。音楽クリップの端点にも Alt＋←／→ で移動できます。

## 開発

```sh
npm test
npm run build
```

テンプレートと調整項目は `src/templates.ts`、時刻からオブジェクトの表示状態を求める処理は `src/animation.ts` にあります。
